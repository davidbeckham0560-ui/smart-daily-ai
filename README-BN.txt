SMART DAILY AI — Version 1.0

এটি একটি মোবাইল-ফ্রেন্ডলি ওয়েব অ্যাপ (PWA)।

যা কাজ করে:
- নোট সেভ/ডিলিট (ডিভাইসের Local Storage)
- টু-ডু লিস্ট (ডিভাইসের Local Storage)
- সাধারণ ক্যালকুলেটর
- ক্যাপশন/স্ট্যাটাস/বায়ো/আইডিয়া টেমপ্লেট
- অফলাইন ব্যবহারের জন্য Service Worker

চালানোর সহজ উপায়:
1. ZIP ফাইল Extract করুন।
2. index.html ফাইল ব্রাউজারে খুলুন।
3. অনলাইনে হোস্ট করলে Chrome-এর মেনু থেকে "Add to Home screen" দিন।

গুরুত্বপূর্ণ:
- এটি APK নয়; এটি ইনস্টলযোগ্য ওয়েব অ্যাপ।
- প্রকৃত AI চ্যাট/জেনারেশন চালাতে AI API key এবং নিরাপদ backend লাগবে। API key সরাসরি index.html-এ রাখবেন না।
- PWA offline cache ঠিকভাবে কাজ করতে HTTPS বা localhost-এ চালানো ভালো।
- সম্পূর্ণ বিনামূল্যে হোস্টিংয়ের জন্য GitHub Pages ব্যবহার করা যায়; অ্যাকাউন্ট/সেটআপ প্রয়োজন।
